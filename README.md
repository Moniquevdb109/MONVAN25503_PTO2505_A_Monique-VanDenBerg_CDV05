# Monique Van Den Berg — Developer Portfolio (CDV05)

A personal developer portfolio website built with React and CSS, showcasing my work experience, projects, skills, and contact information.

## 🚀 Tech Stack

- React
- CSS
- Google Fonts

## 🖥️ How To Run Locally

1. Clone the repository
2. Navigate into the project folder
3. Install dependencies
4. Start the development server
5. Open in your browser

## 📌 Sections

- **About** — Introduction and summary
- **Experience** — Work history
- **Projects** — Showcase of development projects
- **Skills** — Technical and professional competencies
- **Contact** — Contact form and details
